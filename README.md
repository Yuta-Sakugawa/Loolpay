## 1. 背景・目的

### 1.1 背景
ベトナムでは現金による支払いが多く利用されている一方、QR決済や電子決済も普及し始めている。しかし、店舗ごとに利用可能な決済方法が異なるため、利用者が支払い時に困るケースがある。どの店舗でどの決済方法が利用できるか分かりにくいという課題があるため、店舗ごとの決済方法を共有できるシステムを開発し、利用者が事前に決済情報を確認できる環境を整える。

---
## 質問内容
１.  支払方法は何を使っているのか（現金/クレジットカード/QRコード/その他）
２.  ベトナムでは現金を使うことが多いのか？
---

### 1.2 目的
現地利用者が、「この店でクレジットカードが使えるか」「QR決済に対応しているか」「現金のみか」を事前に確認できるようにする。また、現地調査で取得した情報を蓄積・共有することで、実用的な地域情報サービスを目指す。


---

## 2. ターゲットユーザー

| 区分 | 想定ユーザー | ニーズ |
|---|---|---|
| 投稿者・閲覧者 | 現地周辺の住民 | 訪問場所の決済情報の記録・他ユーザーとの情報共有 |
| 閲覧者 | 現地周辺の住民 | 訪問予定場所の決済情報を確認できる |

---

## 3. 機能要件

### 3.1 機能一覧

| ID | 機能名 | 概要 | 認証 |
|---|---|---|---|
| F-01 | 店舗検索 | 店舗を検索 | 要 |
| F-02 | 店舗詳細 | 店舗の場所の詳細（写真・決済情報）を表示 | 要 |
| F-03 | 店舗投稿 | 名前・カテゴリ・住所・メモ・決済情報・写真を投稿 | 要 |
| F-04 | 店舗編集 |　投稿された店舗情報を編集 | 要 |
| F-05 | 店舗削除 | 投稿された店舗情報を削除 | 要 |
| F-06 | 店舗画像の表示 | 投稿された店舗情報の画像を表示 | 要 |

### 3.2 権限ルール

- **閲覧**：全ユーザーは店舗の情報を閲覧できる
- **投稿**：全ユーザーは店舗の情報を投稿できる
- **編集・削除**：全ユーザーは店舗の情報を編集・削除できる

### 3.3 スコープ外（v0.1 では実装しない）

- 通知機能
- 多言語対応（日本語のみ）
- メニュー（商品など）
- 細かな支払方法
